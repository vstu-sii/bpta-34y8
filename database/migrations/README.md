# Миграции после начальной схемы

Начальная версия находится в `../schema.sql`. Последующие SQL-миграции
именуются `002_<change>.sql`, `003_<change>.sql` и применяются по порядку.
Перед миграцией нужна резервная копия; изменение схемы не выполняется
автоматически при запуске существующего volume. Runner появится в лабе 3.
