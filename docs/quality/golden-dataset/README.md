# Golden dataset v2.0.0

Полное описание набора, источников, покрытия UC и команд проверки:
[README_QALITY.md](README_QALITY.md).

**Происхождение набора и проверок.** Вопросы, эталонные ответы и примеры ответов
студента подготовлены с помощью Codex по предоставленному учебному материалу;
это синтетические контрольные примеры, а не ответы реальных участников.
Сверка источников, рубрик и запуск автоматических проверок выполнены с помощью
Codex. Примеры в unit-тестах проверяют инструмент и не являются результатами
вызова модели. Авторство монографии сохранено за её авторами, указанными
в [реестре источников](source-registry.json). Эта запись относится к manifest,
аудиту, генератору набора и тестовым fixtures.
