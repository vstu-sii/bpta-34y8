56 3.4. Типовые структуры конфигурации сопроцессора для различных типов задач 3.4.1. Критерии для задач, решаемых с помощью реконфигурируемого сопроцессора Одним из наиболее важных вопросов при использовании FPGA в качестве сопроцессора является реализации схем систем взаимодействия центрального процессора и блоков, реализующих вычисления на FPGA. Помимо блоков, осуществляющих непосредственные вычисления, схемы систем взаимодейс твия должны включать в себя дополнитель ную периферию для передачи да нных, для хранения исходных данных и результата, для управления вычисл ительными блоками. В зависимости от определенных особенностей реализуемых алгоритмов системе требуются ресурсы разного типа. Исходя из этого, выдел ены следую щие наиболее значимые при разработке данных систем критерии для решаемых задач: 1) Объем пересылаемых данных между FPGA и CPU: а) обработка массивов данных ( например, пример, блоки в криптографических алгоритмах); б) многократные вычисления над небольшим о бъемом данных (пример, задача восстановления строки по md5-хэшу). 2) Наличие сложной логики, управляющей процессом решения задачи (например, QR-разложение). Для алгоритмов, производящих многократные вычисления над небольшим объемом данных, в состав систем ы взаимодействия необходимо включить, как минимум, контроллер PCI Express. Для алгоритмов, осуществляющих обработку массивов данных, в состав системы взаимодействия потребуется добавить устройства памяти для хранения входных, обрабатываемых данных и резул ьтата вычисления.
