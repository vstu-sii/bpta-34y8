Реализация схемы взаимодействия для задач со сложной управляющей логикой Зачастую при разработке аппаратных схем для архитектуры FPGA возникают трудности при реализации сложной логики управления вычислениями на языках аппаратного описания. Данную проблему можно решить, используя в своих системах встраиваемый в кристалл FPGA процессор общего назначения Nios II [33]. Данный процессор реализуется непосредственно с помощью логических элементов в самом кристалле FPGA. Сложная логика управления процессом решения задачи разрабатывается с помощью языка высокого уровня и выполняется на встраиваемом процессоре. Подробнее рассмотрим, что собой представляет процессор Nios II. Семейство программных процессоров Nios II - это второе поколение встраиваемых процессоров о бщего назначени я с перестраиваемой конфигурацией. Эти процессоры используются в FPGA компании Altera. Системы на базе Nios II позволяют программно создавать и и спользовать процессоры, соответствующие потребностям встраиваемой сист емы. Встраиваемое ядро процессора Nios - конвейерный RISC процессор, в котором команды выполняются за один цикл частоты синхрон изации.
