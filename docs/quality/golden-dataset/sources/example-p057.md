Реализация схемы взаимодействия для задач, осуществляющих многократные вычисления над небольшим объемом данных Аппаратные схемы систем взаимодействия реализуются с помощью средства разработки Altera Qsys (версия 11.1). Altera Qsys представляет собой программное обеспечение для автоматического проектирования различных программно -аппаратных средств компьютерной техн ики и представляющее собой различные HDL модули: контроллеры памяти, интерфейсы и периферийное оборудование. Итак, первый вариант схемы предназначен для задач, не требующих пересылки больших объемов данных (например, задача восстановления строки по MD5-хэшу). Предполагаются многократные вычисления над небольшим объ емом данных. Данная система может быть использована для тестирования схем устройств. Разработанная система позволяет осуществлять контроль над вычислительными блоками путем записи/чтения управляю щих регистров устройств. Основные блоки, входящие в состав данного варианта системы, пре дставлены на рисунке 3.8.
