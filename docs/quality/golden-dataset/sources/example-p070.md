В следующем пункте рассмотрим основные под ходы к разработке схемных решений и состав необходимых программных средств. 4.2 Подходы к разработке схемных решений и состав необходимых программных средств Схемные решения для РС строятся либо непосредственно путем создания схем с помощью графических редакторов САПР (довольно редко), либо, чаще всего, с помощью языков описания аппаратуры (Hardware Descriptive Languages–HDL), либо – с использованием средств высокоуровневого проектирования ( High-Level Synthesis – HLS). В последнем случае используется либ о непосредственно язык высокого уровня (ЯВУ, High Level Language – HLL), либо специализированное расширение такого языка, либо – технология программирования, поддерживающая язык высокого уровня и адаптированная для генерации схемных решений. Кроме того, с хемные решения для РС обычно встраиваются в какое -то стандартное аппаратное окружение, включающее локальную память, систему контроллеров и адаптеров, предназначенное для управления памятью, аппаратным интерфейсом платы сопроцессора и взаимодействием между сопроцессором и хостом (подобное описанному в предыдущей главе). Поскольку аппаратное обеспечение РС строится на базе ПЛИС, средства разработки схемных решений строятся на базе соответствующих САПР ПЛИС.
