## Нормализованная запись формул

Формула (2.4), нормализованная запись по изображению: t_comp = (N_elements * N_operations_per_element) / (f_clock * throughput_process). t_comp — время вычислений; N_elements — количество элементов; N_operations_per_element — операций на элемент; f_clock — частота, тактов в секунду; throughput_process — операций за такт. Знаменатель должен быть положительным. Единица t_comp — секунда.
