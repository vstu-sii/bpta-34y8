21 RAT использует три критерия для определения целесообразности реализации алгоритма на FPGA: пропускную способность , число вую точность и необходимые ресурсы. Данные факторы являются доминирующими при оценке полн ой эффективности реализации алгоритмов на конкретной элементной базе. Анализ пропускной способности позволяет предсказать производительность приложения, используя несколько простых уравнений, основываясь на известных параметрах (например, скорость обмена д анными между CPU и сопроцессором) и значениях, характерных для конкретного алгоритма (например, объем передаваемых данных). Анализ числовой точности оценивает пропускную способность, исходя из требований алгоритма к формату данных и связанных с ним возможн ых погрешностей. Анализ необходимых ресурсов подразумевает оценку аппаратных средств, которые потребуются для реализации выбранного алгоритма. Методология RAT предполагает, что первоначально определяется необходимая точность приложения, затем проводится те ст пропускной способности для получения прогнозируемой производительности алгоритма. Числовая точность должна быть сбалансирована относительно типа и количества доступных ресурсов для поддержки требуемого формата.
