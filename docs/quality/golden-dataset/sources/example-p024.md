## Нормализованная запись формул

Формулы (2.5) и (2.6), нормализованная запись по изображению: t_RC_SB = N_iterations * (t_comm + t_comp). t_RC_DB ≈ N_iterations * max(t_comm, t_comp). N_iterations — число итераций обмена и вычислений; t_comm — время обмена, t_comp — время вычислений. SB — одиночная буферизация без наложения обмена и вычислений; DB — двойная буферизация с их перекрытием. Для DB в книге указан приближённый знак, а не точное равенство.
