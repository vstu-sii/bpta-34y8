## GD-001 — QS-UC-01 / definition

**Страница PDF:** 8. **Действие:** `generate`.

**Вопрос:** Как авторы различают гибридную и просто неоднородную систему? Почему различие не сводится к скорости узлов?

**Эталонный ответ:** В используемом авторами различении гибридность означает принципиально разные архитектуры подсистем, а неоднородность может означать лишь различную производительность узлов одного типа. Поэтому разница скоростей сама по себе не доказывает архитектурную гибридность.

**Обоснование:** Ответ опирается на страницу источника. Существенные пункты: Для гибридной системы характерны принципиально разные архитектуры подсистем; Неоднородная система может состоять из различающихся по производительности узлов одного типа

**Источник:** [снимок страницы 8](sources/example-p008.md).

## GD-008 — QS-UC-02 / formula

**Страница PDF:** 23. **Действие:** `generate`.

**Вопрос:** Запишите (2.4), объясните размерность и вычислите t_comp для 1000 элементов, 20 операций на элемент, f_clock = 100 МГц и throughput_process = 4 операции за такт.

**Эталонный ответ:** t_comp = (N_elements * N_operations_per_element) / (f_clock * throughput_process). Числитель — операции, знаменатель — операции в секунду; результат — секунды. Для данных вопроса: 1000 * 20 / (100000000 * 4) = 0,00005 с = 50 мкс.

**Обозначения:** t_comp — время, с; N_elements — число элементов; N_operations_per_element — операций на элемент; f_clock — тактов в секунду; throughput_process — операций за такт

**Обоснование:** Ответ опирается на страницу источника. Существенные пункты: Число операций равно N_elements * N_operations_per_element; Производительность равна f_clock * throughput_process; Деление операций на операции в секунду даёт секунды; При заданных в вопросе параметрах t_comp = 50 мкс

**Обоснование:** Ответ опирается на страницу источника. Существенные пункты: t_RC_DB ≈ N_iterations * max(t_comm, t_comp); Двойная буферизация перекрывает обмен и вычисления; Книга задаёт приближённую оценку, определяемую более длительной стадией; Для данных вопроса DB ≈ 500 мс, SB = 800 мс; отношение оценок SB/DB ≈ 1,6
