# План Golden Dataset

## 1. Назначение

Golden Dataset используется для проверки качества системы
«Карточки для повторения из конспекта».

Набор содержит входные данные и заранее определённый ожидаемый результат.
Он нужен для того, чтобы сравнивать результаты разных версий системы
по одним и тем же примерам.

Основная единица датасета:

**фрагмент конспекта → эталонная карточка**

Эталонная карточка содержит вопрос и правильный ответ.

---

## 2. Источники примеров

Планируется собрать 30–50 примеров.

Основные источники:

- реальные учебные конспекты студентов;
- примеры и проблемы пользователей, полученные во время интервью;
- материалы, предоставленные участниками команды;
- специально подготовленные тестовые фрагменты для проверки
  граничных случаев.

Приоритет имеют реальные пользовательские примеры.

Первые 10 примеров после получения результатов интервью
будут отобраны из наиболее часто встречающихся пользовательских
сценариев и проблем.

---

## 3. Что можно использовать

В Golden Dataset можно включать:

- собственные конспекты участников команды;
- материалы, на использование которых получено разрешение;
- открытые учебные материалы;
- синтетические примеры, созданные командой специально для тестирования.

Для каждого примера необходимо указывать источник.

---

## 4. Что нельзя использовать

В датасет не должны попадать:

- персональные данные пользователей;
- закрытые материалы без разрешения;
- конфиденциальная информация;
- полные тексты материалов, защищённых авторским правом,
  если отсутствует разрешение на их использование.

Если используется реальный пользовательский конспект,
из него необходимо удалить персональные данные.

---

## 5. Формат данных

Для каждого примера сохраняются следующие поля:

- `id` — идентификатор примера;
- `source` — происхождение примера;
- `input_text` — исходный фрагмент конспекта;
- `question` — эталонный вопрос карточки;
- `reference_answer` — эталонный ответ;
- `category` — тип материала;
- `version` — версия примера.

Пример:

```json
{
  "id": "GD-001",
  "source": "test-note",
  "input_text": "Python — высокоуровневый язык программирования общего назначения.",
  "question": "Что такое Python?",
  "reference_answer": "Высокоуровневый язык программирования общего назначения.",
  "category": "definition",
  "version": "1.0"
}
```

---

## 6. Хранение и версионирование

Golden Dataset хранится в репозитории проекта.

Планируемое расположение:

`data/golden_dataset/`

Основной файл:

`golden-dataset.json`

Изменения датасета выполняются через Git,
поэтому история изменений сохраняется в репозитории.

Для существенных изменений версии датасета
используется номер версии.

Например:

- v0.1 — первые 10 примеров;
- v0.2 — расширение набора;
- v1.0 — согласованный набор для автоматической оценки.

---

## 7. Владелец датасета

За структуру, качество и актуальность Golden Dataset
отвечает участник команды с ролью Quality & Safety.

Изменение эталонных результатов выполняется после обсуждения
с командой.

При необходимости спорные примеры согласуются с Product.

# Дальнейшее расширение

После получения материалов от Product необходимо:

1. изучить результаты пользовательских интервью;
2. выделить основные боли и сценарии использования;
3. заменить или дополнить первые тестовые примеры реальными;
4. увеличить Golden Dataset до 30–50 примеров;
5. добавить сложные и неоднозначные случаи;
6. использовать этот набор для автоматических evals в следующих лабораторных работах.
