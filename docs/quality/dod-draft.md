# Definition of Done (DoD) — Lab 2

Проект: «Карточки для повторения из конспекта»  
Ответственный: Quality & Safety  
Статус: Draft

## Цель

Definition of Done определяет минимальные критерии, при выполнении которых артефакты команды для лабораторной работы №2 считаются готовыми.

Каждый критерий должен быть проверяемым в одном из форматов:

- есть / нет;
- числовое значение;
- ссылка на артефакт или результат проверки.

---

## 1. Генерация карточек

Артефакт считается готовым, если:

- [ ] карточки формируются из исходного текста конспекта;
- [ ] каждая карточка содержит вопрос и ответ;
- [ ] вопрос соответствует содержанию исходного текста;
- [ ] ответ можно подтвердить по исходному тексту;
- [ ] отсутствуют пустые вопросы и ответы;
- [ ] отсутствуют явно дублирующиеся карточки;
- [ ] результат генерации сохранён и доступен команде.

Формат проверки: есть / нет, ссылка на пример результата.

---

## 2. Golden Dataset

Артефакт считается готовым, если:

- [ ] создан файл `data/golden_dataset/golden-dataset.json`;
- [ ] в наборе содержится не менее 30 примеров;
- [ ] целевой объём набора — 30–50 примеров;
- [ ] каждый пример содержит поля:
  `id`, `source`, `input_text`, `question`,
  `reference_answer`, `category`, `version`;
- [ ] для каждого примера указан источник;
- [ ] отсутствуют персональные и конфиденциальные данные;
- [ ] спорные эталонные ответы согласованы с командой;
- [ ] версия датасета указана и хранится в Git.

Формат проверки: число примеров, есть / нет, ссылка на файл.

---

## 3. Проверка качества

Артефакт считается готовым, если:

- [ ] генерация проверена на Golden Dataset;
- [ ] рассчитаны согласованные командой метрики качества;
- [ ] результаты проверки сохранены;
- [ ] обнаруженные ошибки или неуспешные примеры зафиксированы;
- [ ] результаты можно повторно проверить на той же версии данных.

Формат проверки: числовые значения метрик, ссылка на результаты.

---

## 4. Безопасность данных

Артефакт считается готовым, если:

- [ ] в тестовых данных отсутствуют персональные данные;
- [ ] отсутствуют закрытые или конфиденциальные материалы;
- [ ] для используемых источников известно происхождение данных;
- [ ] материалы, которые нельзя использовать без разрешения, не входят в Golden Dataset.

Формат проверки: есть / нет.

---

## 5. Документация и воспроизводимость

Лабораторная работа считается готовой, если:

- [ ] необходимые файлы находятся в репозитории;
- [ ] структура файлов соответствует структуре проекта;
- [ ] указаны версии используемых данных;
- [ ] результаты проверки можно воспроизвести по материалам репозитория;
- [ ] ссылки на основные артефакты доступны команде.

Формат проверки: есть / нет, ссылки на файлы.
