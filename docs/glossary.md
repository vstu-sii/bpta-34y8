# Глоссарий

## Пополнение глоссария

`glossary.md` — живой документ. Команда обращается к нему при формулировании требований, подготовке промптов, реализации.

- Любой участник может предложить термин или уточнение: название, определение.
- Владелец глоссария следит за фиксацией решений.
- По мере развития проекта словарь может расширяться; текущая версия содержит 18 основных терминов.


## Термины предметной области

| Термин | Определение и граница понятия                                                                                                                                                  |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Студент | Пользователь, который готовится к проверке знаний по своим материалам, одобряет карточки и повторяет их.                                                                       |
| Учебный материал | Загруженный конспект, лекционный PDF или текст учебника, из которого создаются карточки. Это источник содержания.                                                              |
| Фрагмент источника | Ограниченная часть учебного материала с сохранённым местоположением: страница PDF или блок обычного текста. Используется для извлечения знаний и проверки содержания карточки. |
| Кандидат | Понятие, утверждение, связь, последовательность или формула, выделенные из фрагмента как возможный предмет повторения.                                                         |
| Карточка для повторения | Учебная единица с вопросом или заданием, эталонным ответом, рубрикой проверки и связью с источником.                                                                           |
| Карточка «вопрос — ответ» | Карточка с коротким вопросом и коротким эталонным ответом, проверяющая одно понятие, факт или связь.                                                                           |
| Карточка-конспект | Карточка, в которой студент воспроизводит краткую суть одной ограниченной темы по заданию. Эталон — сжатое объяснение.                                                         |
| Карточка с формулой | Карточка, проверяющая формулу: обозначение, условие применимости.                                                                                                              |
| Привязка к источнику | Связь карточки с исходным документом, страницей или блоком и фрагментом-основанием.                                                                                            |
| Фрагмент-основание | Точный отрывок источника, подтверждающий содержание эталонного ответа. Наличие отрывка проверяется программно.                                                                 |
| Эталонный ответ | Ответ, подготовленный по источнику и показываемый студенту для сверки.                                                                                                         |
| Свободный ответ | Ответ студента своими словами без выбора из готовых вариантов. Синонимы и перефразирование допустимы, если сохраняют требуемый смысл.                                          |
| Семантическая проверка ответа | Сопоставление свободного ответа с рубрикой и фрагментом-основанием по смыслу. Модель объясняет найденные и недостающие элементы.                                               |
| Колода | Набор карточек по учебному материалу или теме подготовки. Колода хранит содержание; очередь повторения выбирает из него актуальные карточки для конкретного студента.          |
| Сессия повторения | Последовательность повторений нескольких карточек за один подход студента.                                                                                                     |
| Планировщик повторений | Программный компонент, рассчитывающий следующую дату показа карточки по истории и результатам повторений.                                                                      |
| Очередь повторения | Список одобренных, доступных для повторения карточек, назначенных конкретному студенту на текущий день.                                                                        |
| Удержание знания | Способность студента воспроизвести изученное спустя время. Проверяется отложенным повторением.                                                                                 |
