# UC-05. Оценка свободного ответа студента

**Актёр:** Студент (основной), Система (ИИ-агент, как инструмент оценки)

**Цель:** получить мгновенную и понятную обратную связь по текстовому ответу, чтобы понять, что усвоено, а что упущено

**Предусловия:** студент ввёл текстовый ответ на карточку в процессе сессии повторения (UC-04)

**Триггер:** студент нажимает кнопку «Проверить ответ»

## Описание
Это микро-сценарий, встроенный в сессию повторения. Студент написал ответ своими словами. Система сравнивает его смысл с эталонным ответом и исходной цитатой, а затем выдаёт структурированную оценку, указывая на сильные стороны и пробелы в ответе.

## Начальное состояние
- Студент видит карточку с введённым им текстом ответа.
- Кнопка «Проверить ответ» активна.

## Успешный сценарий (happy path)
1. Студент нажимает «Проверить ответ» и видит индикатор загрузки.
2. Студент получает результат: статус оценки («Верно», «Частично верно», «Неверно»), список смысловых пунктов, которые он упомянул, и тех, которые упустил.
3. Студент читает краткое объяснение и эталонный ответ.
4. Студент нажимает «Понятно» или «Далее», подтверждая, что ознакомился с обратной связью.

## Альтернативные сценарии
- **2а. Система не уверена в оценке.** Студент видит пометку «Требуется самопроверка». Система показывает эталонный ответ и просит студента честно выбрать: «Знал» или «Не знал». Студент делает выбор, и система обновляет расписание на основе этого решения.
- **2б. Студент не согласен с оценкой.** Студент нажимает «Оспорить». Система сохраняет этот спорный случай в журнал для будущего улучшения, но всё равно просит студента указать, как он сам оценивает свой ответ.

## Негативные сценарии (error handling)
- **1а. Ошибка сети или тайм-аут.** Студент ждёт, но ответ не приходит. Система сообщает о проблеме соединения и автоматически предлагает студенту оценить свой ответ самостоятельно (как в сценарии 2а).
- **1б. Сбой сервиса оценки.** Система не может провести проверку. Студенту предлагается пропустить эту карточку или оценить себя вручную.

## Конечное состояние
- При успешном сценарии — студент ознакомлен с оценкой, расписание повторения карточки обновлено.
- При негативных сценариях — карточка остаётся в очереди, студент может повторить попытку или перейти к самооценке.

## Результат
Текстовый ответ студента оценён по смыслу, предоставлена понятная обратная связь, интервал следующего повторения скорректирован.

## Как поймём, что работает
- Студент получает оценку в формате «Верно / Частично верно / Неверно» с пояснением упущенных пунктов.
- Время оценки одного ответа не превышает 2–3 секунд.
- В случаях низкой уверенности или сбоев сети студент не блокируется, а может провести самооценку.
- Все случаи «Оспорить» корректно сохраняются в системе без потери данных.
