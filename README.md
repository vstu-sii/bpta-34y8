Учебный командный проект по дисциплине «Системы искусственного интеллекта».

## О проекте

Репозиторий предназначен для командной разработки проекта в рамках курса
«Системы искусственного интеллекта». 

Проект  заключается во внедрении искуственного ителлекта в процесс подготовки по конспекту.

В качестве входных данных имеются сам коспект и список вопросов по зачёту. 

Агент должен сформироовать карточки, представляющие собой краткую версию информации представленной в конспекте по каждому из вопросов. 

Кроме того, карточки должны повторяться с определённой частотой на основе арифметики по кривой забывания. 

Степень запоминания материала регулируется  на основе ответов, выдаваемых студентом. 

Формат ответа от студента - текст. 


## Структура проекта

Структура репозитория будет формироваться по мере развития проекта.

Текущая структура репозитория:

- `src/agent/` — логика ИИ-агента
- `src/model/` — взаимодействие с моделью
- `src/app/` — основная логика приложения
- `tests/` — тесты проекта
- `docs/` — документация
- `config/` — конфигурационные файлы
- `.github/` — шаблоны и настройки GitHub
- `.github/PULL_REQUEST_TEMPLATE.md` — шаблон описания Pull Request
- `compose.dev.yml` — конфигурация Docker Compose для dev-окружения
- `.env.example` — пример переменных окружения
- `.gitignore` — список файлов и каталогов, которые не должны попадать в Git
- `CONTRIBUTING.md` — правила работы с репозиторием
- `README.md` — описание проекта и инструкция по запуску

### Требования

Для запуска dev-окружения необходимо установить:

- Docker
- Docker Compose

### Переменные окружения

В репозитории находится файл `.env.example`, содержащий шаблон необходимых
переменных окружения.

После клонирования репозитория необходимо создать локальный файл `.env`.

Для PowerShell:

```powershell
Copy-Item .env.example .env
```
### Запуск dev-окружения

Запуск выполняется командой

```powershell
docker compose -f compose.dev.yml up -d
```

проверка состояния сервисов:

```powershell
docker compose -f compose.dev.yml ps
```

остановка окружения:

```powershell
docker compose -f compose.dev.yml down
```
