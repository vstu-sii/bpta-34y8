# Прототип основных экранов

Запуск из корня: `python -m http.server 8080 --directory frontend/prototype`.
Открыть http://localhost:8080. Также отдаётся сервисом web в Compose.

Маршрут демонстрации: материалы → пример черновика → исправить/принять →
повторить сегодня → свободный ответ → показать эталон → самооценка.
Удалённая карточка не попадает в повторение. Все данные в памяти страницы,
нет API, генерации, загрузки PDF, аккаунтов или устойчивого хранения.
Изменение исходного текста отклоняется, чтобы не показывать фиктивную генерацию.
Изменённые вопросы также отклоняются: модель в демонстрации их не обрабатывает.

Скриншоты: `screenshots/upload.png`, `approval.png`, `review.png`, `mobile.png`.
Проверены переходы, удаление карточки, самооценка и отсутствие горизонтального
скролла на ширине 390 px, Tab-переход между полями и отсутствие JS-ошибок.
Полная проверка доступности и приёмка UC человеком ещё нужны.
Повторить съёмку: `npm ci --ignore-scripts`, `npm run check:prototype`.
Скрипт сам поднимает и останавливает локальный сервер на свободном порту.
Windows использует Microsoft Edge; Linux CI — Chromium, установленный командой
`npx playwright-core install --with-deps chromium`. Внешних шрифтов/запросов нет.
